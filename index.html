Work project·P&P Optica

OPAL

One internal platform for planning, on-site data collection and post-processing of training data.

Operator · run screen

About

Every customer project ran through three stages owned by three teams, connected by one spreadsheet. Operators filled it in by hand on production floors, in PPE, with little or no internet.

I researched the real workflow, redesigned the database around it, built the cloud infrastructure and drove the planner and operator modules — offline-first, with automatic sync.

Role
Full-stack developer, UI/UX designer
Stack
  • Svelte PWA
  • Hono
  • PostgreSQL
  • AWS
  • Playwright
  • Figma

Highlights

  • ~25% less time at the customer site
  • ~60% less post-processing time
  • Every on-site session logged, so recurring errors are visible

Side project · open source

AWS Role Switcher

A Chrome extension that switches between client accounts and AWS roles without re-entering anything.

No screenshot · the extension needs a private roles file to show anything

About

Switching between client accounts and AWS IAM roles by hand was slow and easy to get wrong, so I built a Chrome extension to do it in one click. I made it for my own use; it was then adopted by everyone in the software teams.

I designed it with no company data inside: the accounts and roles are loaded from a simple JSON properties file, which is why it could go on GitHub.
